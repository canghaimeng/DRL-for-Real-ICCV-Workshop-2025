Submission Guidelines for DRL for Real Competition

This competition focuses on developing and evaluating disentangled representation learning (DRL) methods for controllable generation. The competition is divided into two main tracks: Single-Factor and Multi-Factor. Participants are expected to submit their models and results following these guidelines.

📋 Submission File Overview

Each track requires specific file formats and content. Please carefully read the specific requirements for your participating track to ensure your submission is complete and compliant.

🎯 Track-Specific Submission Requirements

1. Single-Factor Track

📁 Required Files

Participants must submit batch traversal results based on test set prompts and images, following the test set structure:

  • Traversal Results: scene-object-factor three-level directory structure
  • Factor Folders: Named as traversal_001, traversal_002, etc. (since disentangled models cannot determine factor text descriptions)
  • Latent Variable Files: Corresponding latent variable values for each traversal image
  • cal_biDCI Results: Encoded latent variables for each image in the cal_biDCI folder
📋 File Format

Detailed format requirements for Single-Factor track submissions:

  • Directory Structure: scene/object/factor hierarchy matching test set
  • Traversal Folders: Each traversal_XXX folder contains reconstruction results from traversing latent variables in one dimension
  • Image Files: Reconstructed images from latent variable traversal
  • Latent Files: Corresponding latent variable values for each image (must maintain order correspondence)
  • cal_biDCI: Encoded latent variables for images in cal_biDCI folder (order must match image sequence)

2. Multi-Factor Track - General Image Dataset

🏆 Main Leaderboard Submission Requirements

Participants only need to submit generated image files organized in the following structure:

  • Generated Images: Only image files are required for submission
  • Directory Structure: scene-object-factor three-level hierarchy
  • Factor Naming: Factor folder names must match the corresponding group names in prompts
  • Group Correspondence: Maintain consistency between folder names and prompt groups (e.g., Group 0001: eyes color_fur color)
🔬 Disentanglement Leaderboard Submission Requirements

In addition to the main leaderboard requirements, participants must also submit:

  • Generated Images: Same as main leaderboard requirements
  • Latent Variables: NPZ files containing latent variables for each generated image
  • File Organization: Latent variable files should be organized alongside corresponding images
  • File Format: Use .npz format to save latent variables for all generated images together
📝 File Format Requirements

Detailed format requirements for Multi-Factor General Image Dataset track:

  • Directory Structure: scene/object/factor three-level organization
  • Scene Folders: Named according to scene categories (e.g., animal_scene)
  • Object Folders: Named as generated_images_[object] (e.g., generated_images_cat)
  • Factor Folders: Named as traversal_XXX, corresponding to prompt group names
  • Image Files: Generated images placed within factor folders

Disentanglement Track: Include latent_variables.npz files containing latent variables for all generated images in each traversal folder

3. Multi-Factor Track - Autonomous Driving Dataset

🏆 Main Leaderboard Submission Requirements

Participants must submit reconstructed images following the test dataset structure:

  • Reconstructed Images: Only need to reconstruct missing viewpoints
  • Image Count: 100 images per viewpoint (0000.png ~ 0099.png)
  • Directory Structure: Must match test dataset organization
  • Scene Categories: Speed-related and weather-related scenarios
🔬 Disentanglement Leaderboard Submission Requirements

In addition to the main leaderboard requirements, participants must also submit:

  • Reconstructed Images: Same as main leaderboard requirements
  • Latent Variables: NPZ files containing latent variables for each reconstructed image
  • File Organization: Latent variable files should be organized alongside corresponding images
  • File Format: Use .npz format to save latent variables for all reconstructed images together
📝 File Format Requirements

Detailed format requirements for Multi-Factor Autonomous Driving Dataset track:

  • Root Directory: data_reconstruction_resized/
  • Speed Scenarios: accelerate/, constant/, decelerate/
  • Weather Scenarios: clear/, fog/, light/, rain/
  • Location Structure: location_X/viewpoint/frames/
  • Image Files: PNG format, numbered 0000.png to 0099.png
  • Disentanglement Track: NPZ files containing latent variables for each viewpoint (one NPZ file per viewpoint)

4. Multi-Factor Track - Autonomous Driving Dataset (Disentanglement Leaderboard)

📁 Required Files

In addition to the main leaderboard submission requirements, participants must also submit:

  • All Main Track Files: Complete submission from Multi-Factor Autonomous Driving Dataset main track
  • Latent Variable NPZ Files: One NPZ file per viewpoint containing latent variables
  • Coverage: Include latent variables for both reconstructed images and original test set images
  • File Placement: NPZ files saved in corresponding viewpoint directories
📄 File Format

Detailed format requirements for Autonomous Driving Disentanglement track:

  • Main Track Structure: Same directory structure as main leaderboard
  • NPZ File Naming: latent_variables.npz in each viewpoint directory
  • NPZ Content: Latent variables for all 100 images in the viewpoint
  • Variable Organization: Array format matching image sequence order
  • Image Coverage: Include variables for both reconstructed and existing test images

📊 Evaluation Criteria

Submissions will be evaluated based on track-specific criteria. For detailed evaluation metrics and weight distributions, please refer to the Evaluation Details page.

Quick Reference:

  • Single-Factor Track: Image Generation Quality (FID, 50%) + Disentanglement Quality (Bi-directional DCI, 50%)
  • Multi-Factor Track - General Image: Main Leaderboard (LLM+VQA evaluation) / Disentanglement Leaderboard (FID + Bi-directional DCI)
  • Multi-Factor Track - Autonomous Driving: Main Leaderboard (SSIM evaluation) / Disentanglement Leaderboard (FID + Bi-directional DCI)

📦 General Submission Format Requirements

Supported Submission Methods:

  • 📁 Compressed files: .zip or .tar.gz format
  • 🔗 GitHub repository link (recommended)
  • ☁️ Other cloud storage links (ensure access permissions)

⚠️ Important Reminders:

  • Clearly indicate which track(s) and leaderboard(s) you are participating in
  • Ensure all required files are included in your submission
  • Carefully check file formats and naming conventions before submission
  • Large files are recommended to be submitted via cloud storage links
